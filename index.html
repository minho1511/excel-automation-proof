엑셀 · 출고 데이터 자동화

“변환”은 누구나 합니다.
저는 틀리면 멈추는 안전장치를 만듭니다.

출고 데이터는 한 건만 틀려도 오배송·클레임입니다. 그래서 저는 예쁜 변환기보다, 조용한 데이터 오염을 잡아 업로드 직전에 차단하는 검증 게이트에 초점을 둡니다. 아래는 실제 작동하는 데모입니다.

실제 데모 — 제약 출고 ERP → 물류 업로드 변환

상단 안내행 2줄 + 헤더 3행 + 맨 아래 ‘합계’ 행이 섞인, 실무와 똑같은 ERP 파일로 검증했습니다.

구현된 안전장치

  • 헤더 행 자동 감지 — 상단 안내행이 몇 줄이든 ‘품목명+수량’ 있는 행을 헤더로 확정 (양식이 조금 바뀌어도 대응).
  • 합계/소계/총계 행 자동 제외 — 안 걸러 업로드하면 유령 오주문이 생기는 가장 흔한 사고를 원천 차단.
  • 컬럼 동의어 매핑 — 품목코드=상품코드=품번처럼 ERP마다 다른 헤더명을 흡수.
  • 검증 게이트 — 변환 총수량이 원본 합계와 일치할 때만 업로드 파일 생성. 불일치·불량행이 있으면 아예 만들지 않음.
  • 박스/낱개 자동계산 — 입수 기준으로 박스수·낱개수 분리 산출.

진행 방식

  1. 실제 ERP 내보내기 샘플 1개 + 물류사(예: 용마로직스) 업로드 양식을 주십니다.
  2. 24시간 내 실데이터 1차 데모 — 여러분 파일로 실제 변환 결과를 먼저 보여드립니다.
  3. 실컬럼·박스규칙·예외처리를 맞춰 조정 (로직은 그대로, 매핑만 교체).
  4. 더블클릭 실행 파일(.exe) + 사용법 1장 포함해 5일 내 완납.
Windows 더블클릭 실행설치 불필요검증 리포트 자동양식 변경 대응
